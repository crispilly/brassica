# Upstream / Herkunft

Brassica Android basiert auf der freien Android-App **Broccoli**, Version 1.4.7 (F-Droid-Quellstand), lizenziert unter GNU GPL v3.

Brassica ist ein Fork mit zusätzlichen Funktionen wie Multikategoriefilter, Import/Export und Web-Synchronisation.

Die ursprünglichen Copyright- und Lizenzhinweise des Upstream-Projekts bleiben im Android-Quellbaum erhalten.
