# Brassica information website

This directory contains the updated static information pages for Brassica 2.x.

Target paths for the existing public site:

- `website/index.html` → `https://brassica.crispilly.de/`
- `website/de/broccoli.html` → German compatibility/info page
- `website/en/broccoli.html` → English compatibility/info page
- `website/assets/` → shared logo and stylesheet

The pages describe Brassica Web 2.x, Brassica Android 2.x, downloads and the automatic 1.x → 2.x migration.

This directory is source material for the public information site. It is not part of the Brassica Web application's DocumentRoot.
