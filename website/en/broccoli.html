Brassica 2.0

Brassica is a free recipe manager for Web and Android. The Web application provides comfortable browser-based recipe management, while the Android app keeps a full local database and can optionally synchronize with Brassica Web.

What's new in version 2?

Brassica Web 2.0

New routing and front controller, private runtime data outside the public web root, browser-based first setup, cooking mode, multi-category OR/AND filtering and a sync API for the Android app.

Brassica Android 2.0

A dedicated fork of the free Broccoli app with a local database, multi-category filtering, direct import/export of .broccoli and .broccoli-archive, and selective synchronization with Brassica Web.

Brassica Web

  • multi-category filtering with OR or AND
  • cooking mode with large paged instructions and Screen Wake Lock
  • import/export of .broccoli and .broccoli-archive
  • multi-user support, collections and public share links
  • sync API for Brassica Android
  • SQLite database and runtime files outside the public web root

Installation: unpack the Web release, point the DocumentRoot to public/, and open Brassica in a browser. The database and first administrator are created through the browser. No shell setup is required.

Brassica Android

The Android app remains offline-first. Your recipes stay in a local Room database; a Brassica Web server is optional and only required for synchronization.

  • existing cooking assistant with screen kept awake
  • multi-category OR/AND filtering
  • direct import of .broccoli and .broccoli-archive
  • JPG/JPEG/PNG/WebP image import
  • single-recipe and multi-recipe export
  • server and user settings
  • sync preview with recipe/category selection
  • explicit conflict direction instead of silent overwrites

Migrating Brassica 1.x to 2.x

The Brassica 1.0–1.2 database structure is compatible with V2. Brassica 2.x includes automatic browser-based migration.

  1. Back up the complete V1 installation.
  2. Unpack Brassica Web 2.x into a new empty directory.
  3. Copy only the old data/ directory into the root of the new V2 Web installation.
  4. Point the DocumentRoot to the new public/ directory.
  5. Open Brassica in the browser.

On first start Brassica copies the database, recipe images and stored import archives into the new private storage/ layout. The V1 source data is not deleted.

Broccoli file formats

Brassica supports the established Broccoli exchange formats: .broccoli for a single recipe and .broccoli-archive for collections of recipes.
